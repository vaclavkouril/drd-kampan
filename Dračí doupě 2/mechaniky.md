# Základní mechaniky

## Hod na akci
Když postava dělá něco nejistého, hází se:
```
2k6 + příslušný stat + dovednost
```

## Obtížnost (Odl)
PJ určí číslo, které je třeba dosáhnout (7–12 je běžný rozsah).  

## Výsledek hodu
- **≤ Odl – 3** → neúspěch se zhoršením.  
- **Odl – 2 až Odl** → částečný úspěch (něco se povede, ale je komplikace).  
- **≥ Odl + 1** → úspěch.  
- **≥ Odl + 5** → skvělý úspěch (kritický).  

👉 I neúspěch posouvá příběh dál – přináší komplikace nebo nové překážky.
